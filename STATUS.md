# STATUS.md — The Clinical Judgment Guide

## What was built

A complete, self-contained manual for nursing faculty and clinical educators who
want to turn wrong answers into learning — education only, zero patient data,
never medical advice.

**Five practice guides** (`docs/*.md`, ~2,100 words of substantive teaching
content each):

1. `01-debrief-scripts.md` — word-for-word scripts for 5-, 15-, and 30-minute
   post-clinical debriefs, a "instead of X say Y" phrase bank, facilitator
   pitfalls, and steering for common wrong answers.
2. `02-judgment-ladder.md` — a climbable question ladder (Noticing →
   Interpreting → Responding → Reflecting, plus Data floor and Transfer rungs),
   five ready-made ladder chains for common clinical scenes, printable prompt
   cards, and a light "rung reached" grading scheme.
3. `03-family-to-nurse-handoff-teaching.md` — treating the family-to-nurse
   handoff as a first-class handoff: the 90-second doorway script, teach-back
   with "What did I miss?", a fiction kit of role cards for 8-minute triads,
   an observer checklist, and an explicit ethics corner.
4. `04-handoff-rubric-builder.md` — rules for building observable rubrics,
   a fully worked example rubric scored against a sample handoff (3/12 with
   pattern analysis), a blank template, and a two-round reliability check.
5. `05-peer-led-micro-lessons.md` — the 10-minute micro-lesson skeleton
   (Hook → Teach → Show → Try → Exit check), a 12-week rotation plan, the prep
   worksheet, a three-item peer rubric, and facilitation moves.

**Static HTML site** (`site/`, fully generated by the build):
- `site/index.html` — guide cards, print-worksheet index, education-only pills.
- `site/docs/*.html` — the five guides, typeset with tables, quotes, and
  heading anchors for deep links.
- `site/worksheets/*.html` — five print worksheet paired with the guides
  (Debrief Planner, Judgment Ladder Practice Sheet, Family Handoff Role-Play
  Kit, Rubric Builder Worksheet with a 6-row scoring table, Micro-Lesson Prep
  Sheet), each with ruled writing lines, checkbox rows, a red education-only
  reminder box, and a "Fictional examples only" marking.
- `site/worksheets/index.html` + `site/styles.css` (warm serif design,
  `@media print` rules with `@page` margins and page-break control).

**Tooling** (`tools/`, `tests/`):
- `tools/build.py` — a stdlib-only static site generator: tiny markdown renderer
  (headings, tables, lists, quotes, fences, bold/italic/code/links, anchors),
  link rewriting (`.md` → `.html`, cross-tree paths), page templates,
  worksheet data → print pages.
- `tests/test_build.py` — 15 tests, `unittest`, no dependencies.
- `Makefile` — `make build` / `make test` / `make serve` (no `make` binary was
  available in the build environment; use the python commands directly).

## How to run it

```bash
python3 tools/build.py       # rebuild site/ from docs/ (stdlib only, offline)
python3 tests/test_build.py  # build + full verification suite
python3 -m http.server 8000 --directory site   # optional local preview
```

Then open `site/index.html` in any browser. Worksheets print directly from the
browser (print button on each page, or Ctrl/Cmd-P).

## Known gaps / honest limits

- The markdown renderer supports the subset used in this manual (no images,
  nested lists, or inline HTML). If you add docs with fancier constructs,
  extend `tools/build.py` — the leak-check test will catch any gaps.
- `site/` is committed rather than ignored so the site can be browsed or used
  without running the build; rebuild yours with `python3 tools/build.py` when
  editing `docs/`.
- The Rubric Builder's peer "steal a trick" feedback and the judgment-ladder
  "rung reached" marks are light-touch; full formal assessment alignment
  (ACEN/CCNE mapping, etc.) is left to each program.
- Scenarios are all fictional by design; nothing here has been validated as a
  clinical instrument. It is education software, not medical advice.
- `make` is in the Makefile for environments that have it; in this container
  `make` was unavailable, so verification used the python commands directly.
